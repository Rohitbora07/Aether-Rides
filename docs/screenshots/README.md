# Screenshot Directory Guide

Drop your screenshots into this folder using the following filenames (or update the paths in `README.md`):

1. `hero-banner.![alt text](image.png)`        - Main hero preview / mockups banner
2. `01-route-search.png`    - Location search, map route line, and fare estimation
3. `02-live-tracking.png`   - Active ride screen showing live driver marker on the map
4. `03-ai-chat.png`         - Chat dialog showing Gemini AI quick-reply buttons
5. `04-otp-modal.png`       - Pickup / Drop OTP verification modal
6. `05-driver-onboarding.png` - Driver multi-step KYC and document upload screen
7. `06-admin-dashboard.png` - Admin metrics, revenue charts, and partner review panel
